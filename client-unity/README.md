# Ludo Rush Unity Client

This folder is a Unity project scaffold. Open `client-unity` from Unity Hub, then create the first scene using these scripts:

- `LudoRushConfig` asset for backend URL and default mode.
- `LudoRushApiClient` on a networking object.
- `LudoGameController` on a game controller object.

The current slice handles guest auth and quick-match API calls. WebSocket room play and the actual Ludo board are next.
